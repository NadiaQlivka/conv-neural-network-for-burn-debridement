# Burn Severity Classification using CNN

Курсовой проект по разработке и обучению свёрточной нейронной сети (CNN) для классификации степени ожога кожи по фотографиям.

## Технологии

Python, TensorFlow, Keras, NumPy, Matplotlib.

## Функциональность

- Разработка архитектуры CNN с использованием Conv2D, MaxPooling2D, Dense и Dropout.
- Предобработка и нормализация изображений.
- Обучение модели для классификации ожогов по трём степеням тяжести.
- Применение EarlyStopping и ModelCheckpoint для контроля процесса обучения.
- Оценка точности модели и визуализация результатов обучения.
- Предсказание класса изображения с выводом вероятностей.

## Структура проекта

- `main.py` — создание, обучение и оценка нейронной сети.
- `predict_burn.py` — классификация изображения с помощью обученной модели.
- `test/` — тестовые изображения.

## Запуск

Установка зависимостей:

```bash
pip install tensorflow numpy matplotlib
```

Обучение модели:

```bash
python main.py
```

Классификация изображения:

```bash
python predict_burn.py
```

Перед запуском необходимо указать корректные пути к датасету, обученной модели и тестовому изображению в исходном коде.
